# 🌾 TN Farmer Crop Revenue Predictor

A competition-grade ML web app for Tamil Nadu farmers.

## 🚀 Run the App
```bash
pip install -r requirements.txt
streamlit run app.py
```
Then open: http://localhost:8501

## 🧠 ML Models Used (scikit-learn)
- Linear Regression
- Ridge Regression  
- Polynomial Regression (degree 2)

## 🌟 Features
- 20 Tamil Nadu districts with realistic cost factors
- 6 crops: Paddy, Sugarcane, Banana, Turmeric, Cotton, Groundnut
- 3 seasons: Kuruvai, Samba, Navarai
- Risk score with drought & market alerts
- Break-even calculator
- 12-month revenue forecast chart
- Smart advisor tips in Tamil + English
- District-wise & crop-wise revenue charts
- Model comparison dashboard (R², MAE)
- Dark green themed UI with Tamil labels
